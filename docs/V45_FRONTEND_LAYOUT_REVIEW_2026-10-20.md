# V4.4/4.5 前端阶段验收记录 · 2026-10-20

## 范围
本轮**仅完成前端呈现、导航和响应式布局重整**；不修改 156 节课程原文、阶段数据、测试答案、Supabase 用户记录、API Key 或私人文件。课程的教学逻辑与教材内容重构是**下一个独立阶段**，当前尚未开始。已获准的课程预览与正式教材发布状态仍保存在原有可审计文件及数据库中，不通过用户界面重复占据空间。

## 修复与实现
- 沉浸/专注模式：原样式直接将左侧导航设置 `display:none`，而右侧固定近 47% 造成巨幅空白。现在有可点击 `☰` 的导航浮层，支持遮罩关闭、Escape 关闭及点击导航自动关闭，保留历史记录和页面路由。窄屏从桌面缩放时不再突然自动弹出旧导航。
- 阅读区：新布局依赖**实际课程容器宽度**而不依赖 viewport 猜测，超过 940px 为阅读主栏 + 315–420px 右侧工具栏，低于此宽度单列。沉浸页面使用可用宽度，正文宽度与排版按阅读体验收敛，避免右侧超宽。课程主标题、tabs、朗读控制、练习、原文、笔记、附录有统一段距与字号，新增 A−/A＋ 自定义字体缩放按钮。
- 右侧选词：直接复用原有 `SelectionInspector`，只在有内容需要时自动出现；无选词首次进入时全文阅读，无固定空白占位。缩小尺寸自动降为下方工具区，列表内部滚动，选词、读音、跟读、IPA、语境、AI、笔记继续可访问。
- 文案：清理源版本、审校/授权重复提示、前端原型技术说明和无用说明条，覆盖课程、目录、IPA、课程目标、48 节基础补充、设置、旧云端学习面板。保留真实错误反馈、学习题干、课程教学内容、进度操作和必要交互标签。**不删除后台授权记录和审校元数据**。
- 基础与复习页：对 48 节基础课程的语言筛选、目录、知识/单词/听读/发音/练习排版进行 CSS 统一，窄屏改横向可滚动目录。没有改教学顺序，也没有对 108 个主课程自动重写内容。

## 回归边界
- GitHub PR #50 分支预览应覆盖宽屏 (>1400)、中屏约 1024px、手机约 390px 下的标准/沉浸/专注布局；测试选择词句后右侧联动，切换导航、刷新浏览器、关闭工具、放大缩小字体、朗读原文和连续翻页。
