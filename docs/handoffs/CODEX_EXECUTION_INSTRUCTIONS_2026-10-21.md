## 1. 不可协商的产品和教学规则

1. **不允许 AI 废话。**删除学生页面上的“原创完整样课 v0.1”“教学内容草稿”“等待审核”“来源登记”“导入课程”“我们将在下一阶段”“本系统将……”及同类开发工作流说明。学生正文只保留与理解、练习、实际学习任务直接相关的内容；研发说明仅留开发文档/来源元数据。不用空泛总结、机械化说教和重复标签填充空间。
2. **完整的中文对照。**法语、英语的语法、词汇、情境、表达、阅读和练习都需要准确通顺的中文解释。外语实例、真实用法、关键例外、错误对照、对应译文、答案和为什么这样表达应一致；严禁直译硬拼或省略重要前提。
3. **先学基础，再学结构、语境和长输出。**识别层 → 规则或义项 → 变形/搭配/边界 → 语境例句 → 易混点 → 练习解析 → 连贯段落或完整篇章。语法与词汇是独立可深入阅读的知识板块，但必须和原课程打通，不能成为另一个重复页面。
4. **内容以教材为中心。**优先核对仓库已入库教材、已授权原资料、原课程 can_do 与表现任务，再以 Texas Tex、CEFR、France Éducation international、IELTS、British Council 等可靠资料补足。外部资料只作规则对照；自编文本注明“原创练习”，不得伪称官方试题、真实研究或逐字教材。
5. **严格保留语义和证据强度。**例如 si + imparfait → conditionnel、si + plus-que-parfait → conditionnel passé；qui/que/dont/où、bien que/même si、证明/提示/推测、部分/全部、相关/因果、尚未决定/已经实施都不能误写。高频易错规则须在解释、题目和范文三处互相校核。
6. **移除无关模块。**不恢复被用户否定的“课程导入”提示大卡、独立发音教学面板和伪专业评分；保留选中单词/句子的侧栏朗读、文本定位和必要的音频回放。现有数据模型六步与前端五阶段的差异应审慎映射，不能因为调整内核重新添加用户已拒绝的 UI。
7. **宽屏真正利用空间。**1440/1920px 不能只将全部内容锁在中央窄条并在右上与右边留大片空白；左右布局按正文+有内容的辅助信息合理分配。右侧无意义或重复时折叠/收起，主内容获得宽度；主阅读段落仍保留舒适行长，不把超长句拉到整屏。
8. **现有功能不回退。**保持中英/法语言切换、情境/语法/词汇/听读/表达、主题和阅读模式、选词/朗读、答题解析、学习进度、笔记、账号云端同期能力。出现问题先定位根因，不以加按钮、换视觉样式代替修复。
9. **不要拿结构数量冒充质量。**“156 个单元文本存在”“60 节专题已编写”“CI 全绿”均不等于真实教材全面审校、音频对齐或生产发布通过。阶段成果必须标注实际覆盖和剩余范围。

## 4. P2：语法与词汇内容系统化、B2–C2 听读深度（最高课程优先级）

- 从已有 60 节专题和 156 个规划单元找出真实缺口，优先精修已写内容的错误、不自然法语/英语、译文语义和重复示范，再扩充未形成完整教材的单元。严禁用重复段落只为增加“丰富度”。
- 法语 A1/A2：冠词与性数、物主、形容词、词汇搭配、基本时态、方向、生活情境；B1：复合过去/未完成过去/愈过去、条件式、虚拟式、关系代词、观点链；B2–C1：间接转述、时态呼应、新闻/论证/长篇阅读、语域与证据力度、正式写作、跨来源 synthèse；C2 只依据已定义目标和真实材料扩展，不凭空声明已达到官方水平。
- 英语 IELTS：听力讲者目的、转述与笔记；阅读定位、同义改写、True/False/Not Given 与 Not Given 证据边界；Task 1 趋势/流程/地图/表格/比较；Task 2 立场、解释、反方、证据、连贯结论；口语按已有 syllabus 组织，不生成虚假认证评分。
- 课文、阅读、练习必须构成前后链路。长篇阅读要有足以支持题目和摘要的真实篇幅（原创或可合法使用的材料），相应段落编号、答案依据和中文讲解；短文明确为技能微练习，不称官方完整模拟卷。
- 以抽样+规则校验双重审核每次批量编辑：动词形态、搭配、否定位置、时态一致、名词性数/冠词、介词、中文自然程度、题干可作答性、范文是否覆盖题目要求和文本证据。发现错误先修正，再开展下一批。

**P2 通过条件：**差距矩阵里所有本轮纳入范围的课程通过教材正文、完整中外文映射、题目/答案一致性和真实篇章检验；仍未审核的原课程单独列出，绝不能虚构审校通过。
