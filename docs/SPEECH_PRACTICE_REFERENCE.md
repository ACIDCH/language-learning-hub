# 可选音素练习参考值：已接入功能分支（实验性）

2026-10-18。这个功能是面向普通英法学习者的**练习辅助值**，不是专业音素准确率、人工标注音素错误率（PER）、GOP、语音质量或 CEFR 分数。普通使用者不需要安装本机声学模型，免费浏览器跟读始终可用。

## 如何启用

在本机安装/启动可选声学服务（须使用已下载的固定版本 Wav2Vec2 模型和 Python 环境），然后启动 Vite 5174 端口。进入 `http://127.0.0.1:5174/speech-lab`，在“识别方式与高级实验功能”展开后选择“实验性：本机音素练习参考值”，先输入完整英/法短句，点击“录音并观察音素”或选择本机音频。输出合法且模型可判定时，会显示 **0–100 的音素练习参考值**，同时列出 IPA 参考与模型观察，并给出重复练习建议。

参见 [SPEECH_V3_BENCHMARK.md](./SPEECH_V3_BENCHMARK.md) 的本机启动命令；不上传权重，不要求付费 AI 接口。**本功能需要单独运行约 1.26GB 的本机模型权重；公开托管页面仍使用免费浏览器模式，不会自动运行这套模型。**

## 数值到底是什么

- 自动生成的参考音素序列（eSpeak G2P）与 Wav2Vec2 贪心 CTC 解码候选序列之间的编辑序列一致度：`round(100 × (1 − 非匹配对齐项数量 / max(参考音素数,候选音素数)))`，截断至 0–100。
- `percent=100` 只代表**两套自动系统给出的音素序列一致**，不能证明说话者发音正确。`percent=0` 也不能证明学习者全部读错。
- 为减少误导，短参考音素（不足 4 个）、候选音素不足 3 个、超出参考长度 0.5–1.8 倍、生成参考含未知符号、录音信号拒绝、空模型输出都不显示百分比；用户可选择完整短句重试。
- 每次返回 `canScore:false` 和 `calibrated:false`。新增 `practice_reference.percent` 是教学参考，不是专业 `score` 字段。
- 连诵、地区口音、法语鼻化元音、孤立短词、噪声和自动生成 IPA 都可能导致虚假的高分或低分。因此没有“合格线”、名次、学习完成标记、付费认证，也不将此值保存为课程成绩。

## 证据与测试

本次新增纯函数及模拟模型的边界测试、前端接口检查，CI 验证其代码与数据契约。**原有 30 条语句／90 个人工合成音频基准是在新参考算法加入之前产生**；没有新的真人语音准确率测量，更不宣称已经通过 Chrome/Edge 的真实麦克风验收。真人样本 0 和实机待验收的报告必须保持原样。

日常学习推荐：先用默认浏览器识别练习，再按需打开本机音素参考，重点听示范、看模型可能忽略的音、重读目标词。可参考数值，但不要将它看成专业发音诊断。

## 面向开发者的兼容性

- `speech_service/core.py` 的 `practice_reference` 不参与声学模型推理，只处理现有 G2P 与 CTC 的对齐结果。
- 正常样本返回 `practice_reference: {available: true, percent, calibrated: false, ...}`；不可靠样本 `{available: false, percent: null, reason, ...}`。
- `src/LocalPronunciation.tsx` 在用户**已明确选择本机引擎**时展示参考值，不破坏浏览器回退；录音仍限时、仅本机内存，原进度数据库不变。
- 不宣称此模型具有独立“评审正确发音”的能力。后续可通过真人标注测试检验和调整阈值，而不是直接用原始合成基准认可参考分。
