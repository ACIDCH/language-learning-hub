# Français A1 — Unité 01 : Salutations et présentations

**Statut :** échantillon pédagogique original, destiné à relecture; pas encore publié comme leçon audio complète. Liens de référence : [Inspire 1 A1 — audio officiel, unité 1](https://inspire.hachettefle.fr/inspire-1_livre-de-l-eleve_fr.html), [Français interactif — Chapitre 01 Bonjour!](https://laits.utexas.edu/fi/toc/01/), [Tex's French Grammar](https://coerll.utexas.edu/coerll/oer/texs-french-grammar/). **This is our own example, not the textbook's original dialogue.**

## Objectif / 学习目标

能够使用正式和非正式问候语、介绍自己的姓名和国籍、询问对方的名字、区分 `tu` 和 `vous` 的社交使用场景。

## 1. Situation / 情景导入

**原创对话**

> A : Bonjour ! Je m'appelle Léa. Et vous, comment vous appelez-vous ?  
> B : Bonjour, je m'appelle Marc. Enchanté !  
> A : Enchantée ! Vous êtes français ?  
> B : Non, je suis canadien. Et vous ?  
> A : Je suis française. Bienvenue !

中文解读：`Je m'appelle...` 表示“我叫……”；`vous` 通常用于初次见面、正式场合或复数，`tu` 用于熟悉的人之间，具体用法因地区与社交情境而异。注意 `enchantée` 在书面表达中与女性说话者一致，这一拼写差别在通常发音中不体现。

## 2. Grammaire / 语法

**A. 主语人称代词**

`je` 我；`tu` 你（非正式单数）；`il/elle` 他/她；`nous` 我们；`vous` 您／你们；`ils/elles` 他们/她们。法语动词通常随主语变化。

**B. Être（是、处于）的直陈式现在时**

| Pronom | être |
| --- | --- |
| je | suis |
| tu | es |
| il / elle / on | est |
| nous | sommes |
| vous | êtes |
| ils / elles | sont |

**原创例句**

1. Je suis étudiant. — 我是学生（男性说话者）。
2. Je suis étudiante. — 我是学生（女性说话者）。
3. Tu es français ? — 你是法国人吗？（非正式问法）
4. Vous êtes professeur ? — 您是老师吗？（带升调的日常问法）
5. Il est canadien. — 他是加拿大人。
6. Elle est canadienne. — 她是加拿大人。
7. Nous sommes dans la même classe. — 我们在同一个班。
8. Ils sont amis. — 他们是朋友。

**C. 不定冠词初识**

`un étudiant`（一名男学生）、`une étudiante`（一名女学生）、`des étudiants`（一些学生）。`C'est un étudiant.` 与 `Il est étudiant.` 都可以正确表达，但结构和侧重点不同；不要机械地在所有职业表达前都加冠词。

**常见易错点**

- ❌ *Je est français.* → ✅ `Je suis français.`
- ❌ *Vous es étudiant ?* → ✅ `Vous êtes étudiant ?`
- ❌ *Je suis un étudiant.* is **not always wrong**: it is acceptable in some contexts, but `Je suis étudiant` is the standard unmodified profession/student-status introduction. Avoid teaching the first phrase as universally ungrammatical.
- `Je m'appelle Léa` uses the pronominal verb `s'appeler`; present it as a high-frequency chunk first, with full pronominal-verb grammar reserved for a later unit.

## 4. Réception / 听读

**原创微型阅读**

> Bonjour ! Je m'appelle Camille. Je suis française. Mon ami Adam est canadien. Nous sommes étudiants. Nous sommes dans la même classe de français. À bientôt !

理解任务（自选）：谁是法国人？谁是加拿大人？哪一个动词形式对应 `nous`？尝试用中文概括这段文字。

## 5. Phonétique / 发音与跟读

- `u` /y/ 对比 `ou` /u/：练习 `tu` 与 `tout` 的元音差别（两词的主要区别是元音；`tout` 的词尾 `t` 通常不发音）。
- `vous êtes` 的词间连音要结合具体语流示范，不以拼写推断实际音质。
- 法语句子的重音常按节奏组组织，不能机械地给每一个词施加英语式词重音。
- 练习短句：`Je suis étudiante. Vous êtes français ?`
- 在语音引擎通过法语专项验证后，逐词显示绿／黄／橙／红或不确定灰色；不显示总分，也不声称模型能自动识别全部音素错误。

## 6. Application / 应用练习

**无分数的自选练习**

1. Complétez : `Je ___ étudiant.`
2. Complétez : `Vous ___ français ?`
3. Complétez : `Elle ___ canadienne.`
4. Transformez : `Il est étudiant.` → “他们是学生”。
5. Choisissez : 初次见面和不熟悉的人谈话更常用 `tu` 还是 `vous`？
6. Rédigez : 用一句话说“你好，我叫……，我是学生”。

**参考答案：** 1. suis；2. êtes；3. est；4. `Ils sont étudiants.`；5. 通常为 `vous`，但要考虑交际情境；6. `Bonjour, je m'appelle … et je suis étudiant(e).`

**Expression orale**: 用 30–45 秒介绍姓名、学生身份、国籍，再提出两个简单问题。**Production écrite**: 用 5–7 句原创法语介绍自己以及一位同学。AI 可以根据实际文本提供语法与表达建议，不安排考试。
