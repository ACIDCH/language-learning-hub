## 知识链路与关联课程

语法与词汇各自有独立的前后顺序；跨类型只在存在同一真实课程关联时提供“关联语法／词汇”链接，不能用空目录充数。

### 法语语法（从简单句逐步进入复句及过去时）

A1：être 和人称代词 → avoir、物主限定词 → 冠词与存在句 → -er 现在时 → est-ce que / 疑问词 → 形容词性数配合 → aller + 不定式（futur proche）。

A2：部分冠词和数量 → 复合过去时 avoir/être → 未完成过去时及二者的叙事分工 → 直接与间接宾语代词。
