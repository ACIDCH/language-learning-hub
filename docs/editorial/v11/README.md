# Editorial V1.1: IELTS Academic U07–U08 across six tracks

**Scope:** 12 new unit IDs, six complete private Google Docs, 96 worked questions. Each lesson contains its own academic scenario, specific grammar or analysis framework, original substantial listening/reading/task text, targeted vocabulary, eight explained answers, pronunciation goals and an independently authored example response. Materials are IELTS-*style*, not official exam content.

Unique IDs:
- en-ielts-listening-u07, u08: multi-speaker argument tracking; synthesising extended lectures.
- en-ielts-reading-u07, u08: matching evidence across sections; cross-source critical synthesis.
- en-ielts-writing-task1-u07, u08: coherent comparison; numerical and inferential editing.
- en-ielts-writing-task2-u07, u08: referential coherence; evidence and register editing.
- en-ielts-speaking-u07, u08: intelligible connected speech; sustained discussion and repair.
- en-ielts-language-upgrade-u07, u08: referential integrity; feedback that preserves authorial intent.
