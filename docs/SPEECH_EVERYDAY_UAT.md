# 日常学习版发音 V3 — 使用与验收记录

> 当前为主分支候选中的日常学习功能，**不是已经在 Chrome/Edge 真实设备验收的生产版本**。本指南基于一般语言学习，而非专业音素评测。

## 使用目标

普通初学者需要的是：选一个词句 → 听一遍设备示范 → 跟读 → 看看浏览器转写是否与句子大致相符 → 只复练有差异的词 → 返回原句。无需专业口音评级、模型权重或额外支付 API 费用。

使用免费 Web Speech 语音识别与设备 TTS；若浏览器没有相应能力会提供明确提示。具体识别服务可能由浏览器厂商处理语音，不能保证离线。页面不保存录音，最近 5 次转写记录仅在当前组件内存中；切换句子或离开页面后不保留。

## 入口与衔接

1. 登录 `/cloud`，打开“基础衔接课程”，任选一节英语／法语基础或 A2 衔接课（共 48 节）。
2. 切至该课的“5. 发音”环节。会自动给出**本课例句**，同时显示本课词汇、例句、听力与阅读可抽取的练习片段。
3. “① 听示范”播放所选句子，可选择口音与语速；“② 开始跟读”用浏览器识别。文字完全一致也只是**文本转写一致**，并不能证明音素无误。
4. 若有差异，点击“听这个词”→“只练这个词”，之后“返回完整句”再说一次；“换一句练习”可继续本课。
5. 识别完成后，展开“本句跟读记录”查看最近 5 次文字结果；更换句子／课程后清空。
6. 也可在本地 `http://127.0.0.1:5174/speech-lab` 使用不需要账户的通用示例。主课程原有“跟读”面板使用同一组件。

日常学习候选仅使用免费的浏览器语音识别与设备朗读。本机 1.26GB 的 Wav2Vec2 音素模型留在独立的实验分支中，不是普通跟读的依赖。

## 代码层面已覆盖的测试

- 普通识别模式生命周期、断麦、超时、迟到结果、服务缺失、失效语音尝试。
- 不会因转写文字恰好匹配就生成专业评分。
- 法语词语（如 `café`）复练时保留原文重音符号。
- 漏词或词语变化，给出可操作的试听与复练说明。
- 单独练词后可返回同一句，换句后清除历史；重复的浏览器 final 事件只记录一次。
- 每句最近 5 条记录，纯前端内存，不写入 Supabase。
- 48 节课程“发音”环节的跟读组件复用既有课程正文，不新增私人数据副本。

## 真实使用验收（仍待人工）

| 场景 | 期望结果 |
| --- | --- |
| Chrome/Edge：英语与法语短句 | 允许麦克风后展示实际浏览器转写 |
| 同一句故意换词或漏词 | 显示“不一致的词”，可听词、练词、返回原句 |
| 整句听起来正常但转写错误 | 明确标注是识别文本差异，不误判学习者 |
| 禁止麦克风／没声／识别超时 | 可重新尝试，不需要刷新页面 |
| 练词过程中换句或切换语言 | 取消旧录音/旧结果，历史记录清空 |
| 48 节基础课任取英法各三课 | 发音面板的本课例句、阅读和词汇正确，学习笔记／测验不被修改 |
| Cloudflare 静态预览 | 浏览器默认模式仍可显示；高级本机模式不可连接远程服务 |
| 返回词库／音频／进度 | 原有 A1 音频、课程进度和基础课答案正常 |

不需要为了普通跟读功能收集专业音素标注才开始使用；但**真实浏览器的录音、识别和断线流程验收仍必须做**，否则不能宣称麦克风交互已实际可用。

## 仍然不提供的能力

- IPA 级准确率、专家发音分数、强制对齐、可靠的口音判定或 CEFR 认证；
- 各个浏览器／口音必然识别成功的保证；
- 云端持久保存学习者录音；
- 把合成基准数据误写成真人训练或真人质量验证。

独立的研究级音素观察代码和原始合成基准见 [Draft PR #30](https://github.com/ACIDCH/language-learning-hub/pull/30)，日常学习不依赖该服务。
