## V4.4 · 已批准的跟读双面板实施记录（2026-10-20）

- 独立「跟读训练」：主导航 /speech-lab 进入 `SpeechLab`，以课程样句、英语/法语选择、选中文本、播放示范、开始跟读、停止、重试、识别转写与词语差异、单次音频回听、波形/停顿和可选音素色阶为主界面，去掉四步流程与底部无效解释。
- 原课文右侧原本 `SelectionInspector` 仍是**唯一**选词工具，不新建 overlay 或第二套侧栏。新增同一面板的「跟读 / 释义 / 读音 / 语境 / 笔记 / AI 讲解」标签，其中默认的「跟读」直接用独立页面相同的 `SpeechPractice` 状态机与嵌入式 `BrowserSpeechFeedback`。选中任意原文词句即成为练习目标，旧收藏与笔记保留；AI 教师仍复用已有 OpenRouter 账号/Vault 设置、需要本人主动调用。
- 浏览器 Web Speech 转写和本地 WebAudio PCM 测量通过**同一个开始/停止控件**启动；内部为两个浏览器 API 的独立处理，故 Web Speech API 的联网行为取决于浏览器，不冒称 100% 本机 ASR。WebGPU/WASM 多语言音素模型仅在用户另行点击音素色阶按钮后下载使用；真实候选决定色阶，没有任何伪造评分数据。
- 主训练页和右侧工具面板共享同一个实现，但 V3 兼容入口和原有测试仍保留，不改变底层语音处理算法或课程正文数据。
- 交付限度：PR Preview 构建及 mocks 通过 ≠ 用户 Chrome 首次 WebGPU 下载、双 API 麦克风捕获和实时发音效果已经验证。实际硬件验收仍需用户进行。
- 本次不合并 main、不更改正式站、不向 Supabase 上传录音或更改学习记录。
