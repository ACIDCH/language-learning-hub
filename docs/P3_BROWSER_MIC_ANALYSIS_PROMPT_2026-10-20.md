# Language Learning Hub V4.4｜轻量浏览器录音分析（P3 自执行开发 Prompt）

**工作基线**：仅在 `ACIDCH/language-learning-hub` 原 PR #50 当前分支修改，不合并 main、不正式部署。禁止重写 156 节课程、账户、Supabase 进度/设置、OpenRouter、Google Drive 或其他已验收模块。

## 用户真实需求
放弃 Oracle Cloud 及专业音素评分作为使用前提。个人学习者只要打开 Web 页面、允许麦克风、说一句话，即可在**当前浏览器**看到简单且有根据的录音分析，能够回听并重复练习。无需大型模型、云服务器、安装插件、本地 Python 进程或付费服务。延用已有 Web Speech 文字转写、设备 TTS 示范与 IPA；允许与现有可选 AI 教师共存，但不默认发送录音或自动调用 AI。

## 最小交付
1. **纯浏览器**：复用 `src/speechCapture.ts` 的 MediaRecorder → 16 kHz PCM (0.35–12 秒) 链路；在 Web 页添加清楚的「浏览器录音分析」入口，支持开始、停止、取消、麦克风拒绝/超时。
2. **实际分析**：对真实 PCM 的 20ms 帧做 Web 端 DSP，计算录音长度、估计有声时长/内部停顿次数及大致停顿时长、音量能量及削波迹象。不要把环境噪声、气息、无声部分误称为音素错误或官方口语成绩。低信号应显示“音量过低/无法可靠判定”。
3. **可听可用**：允许回听当前浏览器的短录音，给出 1–2 条保守复练建议；更换练习句/页面关闭时撤销 Blob URL、终止麦克风、释放资源。原始音频不得写入 Supabase、Google Drive、localStorage、日志或第三方 AI；保持内存临时态。
4. **协同**：现有「② 开始跟读」仍提供浏览器转写文字差异；本地声学模块独立，不把文字相似度混同声学分数；AI 教师仍只在用户主动开启并发送时使用已有 OpenRouter/Vault 设置。高级本机服务/云端推理可保留兼容入口，但不得要求用户部署 Oracle。
5. **质量门槛**：为静音、有效短句、停顿、削波和 WAV 内存回听编写确定性定向测试；覆盖渲染入口与操作过程；运行现有 GitHub CI 及 Cloudflare Preview。测试通过不等于真实麦克风验收。由用户最终在 Chrome/Edge 授权、录音、听音核对。
6. **结果**：仅在原 PR #50 提交代码、测试和一份集中验收记录；新功能以「无需服务器的浏览器录音分析」标注，不得虚称精准音素、专业评分或 AI 实际听音。

## 执行次序
复用与局部修改 → 加算法和短录音回听 → 集成跟读页面 → 定向测试 → CI/Preview → 汇总最终结果。省 Token，不做全量课程审计，不逐模块询问，不采购/部署云计算资源。
