# Public learning assets

This folder is the **only approved location** for small, independently verified and redistributable learning texts/audio in the public source repository.

- All actual resources must be listed in `manifest.json` and pass `tools/validate_public_assets.py`.
- An empty manifest means **no audio/textbook files have yet been approved or uploaded**.
- Copyrighted textbooks, proprietary publisher audio, personal notes, private generated lessons and recordings belong in the dedicated Google Drive folder instead.
- See [the public asset policy](../../docs/public-asset-policy.md) for license/attribution review and size limits.

The site's source code license, if added later, does not automatically apply to third-party assets.
